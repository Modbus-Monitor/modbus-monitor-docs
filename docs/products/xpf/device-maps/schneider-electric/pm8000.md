# Schneider Electric PM8000 Modbus Register Map

The Schneider Electric PM8000 is a power meter used for power monitoring, energy metering, and facility automation. This page provides a sample Modbus register map with addresses, data types, and signal categories to help engineers commission, troubleshoot, and monitor the device. Commonly used in data centers and high-end power monitoring systems.

This page shows a public register preview. Check the catalog in your installed XPF version for complete-map availability and licensing.
