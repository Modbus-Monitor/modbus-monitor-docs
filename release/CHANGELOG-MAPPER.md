# Modbus Mapper Pro Release Notes

## v1.2.0 — August 3, 2026

- Added permanent Free passive RS-485 monitoring and traffic logging.
- Added RS-485 Replay Emulator and replay exchange recording.
- Improved replay reliability for fragmented, concatenated, and custom Modbus messages.
- Added serial/application metadata to replay and Modbus-map CSV exports.
- Simplified activation, strengthened subscription checks, and clarified Free/Pro feature limits.
- Improved serial stop behavior, diagnostics, live status updates, and settings persistence.
- Added ARM64 portable release support and fixed x86 publish support.

## v1.0.0

- Initial Modbus Mapper Pro portable release.
